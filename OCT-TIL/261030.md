## 파이썬 설치하기 (+ 가상작업환경)(터미널로 진행)

- 새 프로젝트 디렉터리 만들기 
- uv init 하기 (노패키지로, --no-package)
- uv init을 하면 자동으로 깃초기화가 되서, .git과 .gitignore가 생김

## 터미널로 새로운 디텍토리를 만들고 진행 
- 터미널로 퍼스트 프로젝트에서 나감
- 상위폴터로 올라감
- 세컨트 프로젝트를 새로 만듦
- uv init 하기 (노패키지 + 파이썬3.13)
ㄴ uv init --no-package --python 3.13
(이렇게 퍼스트 프로젝트 디렉토리는 3.15버전
세컨트 프로젝트 디렉토리는 3.13버전이다) 
- 버전 수정하는법 
ㄴ cat pyproject.toml (3.13으로뜸)
ㄴ uv python pin 3.12
ㄴ vi pyproject.toml (하면 이상한 화면 뜸)
ㄴ (그 화면에서도 수정할 수 있는데 일단은 닫고
vscode로 진행함) toml파일로 들어가서 수동으로 버전을
3.13에서 3.12으로 편집을 하고 저장하기 
ㄴ uv python pin 3.12 하면 수정됨 
ㄴ uv run main.py 하면 3.12로 나옴.
