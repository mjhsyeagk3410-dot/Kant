# 백업 만드는 방법 
```sh

```

# 리셋(소프트, 믹스드, 하드) 하는 법 
## 소프트 리셋
```sh
git reset --soft 해시값
```
## 믹스드 리셋
```sh
git reset --mixed 해시값 
```
## 하드 리셋
```sh
git reset --hard 해시값
```
## 잘못 리셋을 했다. 돌이킬 수 없다. 최후의 보루 
```sh
git reflog
```
### 돌아가야할 위치 
```md
해시값 HEAD@{숫자}: commit: docs: add push command
```
### 돌아가는 위치로 이동할때
```sh
git reset --hard HEAD@{1}
```
HEAD@{?}의 숫자는 작업을 하는 환경에 따라 다를 수있음.  

# 브랜치 만들고, 지우고, 변경하는 법 
## 새로운 브랜치 만들기
```sh
git branch 새 브랜치 이름
```

### 브랜치가 잘 만들어졌는지 확인하기 
```sh
git branch
```
## 메인 브랜치에서 새로운 브랜치로 바꾸고 그 반대로도 하는법 
```sh
git checkout feature/login
```
```sh
git checkout main
```

## 새로운 브랜치 지우기  
```sh
git branch --delete 브랜치이름
```

### 새 브랜치를 만들고, 브랜치 스위치없이 바로 그 브랜치로 가는법 
```sh
git checkout -b feature/login
```

# 새 브랜치를 메인 브랜치와 머지하는 법 
```sh
git merge feature/login
```
