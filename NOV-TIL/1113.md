## 01 SQL과 쿼리문이 뭔지? 
- SQL
```md
Structured Query Language(구조적 질의 언어)로써, 관계형 데이터베이스(MySQL, Oracle, PostgreSQL 등)에 있는 데이터를 관리, 조작하기 위해 사용하는 표준 프로그래밍 언어입니다. 
```
- 쿼리문(SQL Query)
```md
SQL언어를 이용해 데이터베이스에 실제로 내리는 '명령문(질의)를 뜻합니다. "데이터베이스에 무엇을 하라"고 요청하는 구체적인 코드 한 줄 또는 블록입니다. 
```
## 02 vs code에서 SQL 테이블 만들어보기 
```sh
## sql파일은 kant_shop.sql 이렇게 만든다
## 쿼리문에서는 앞에 ## 부분을 -- 이렇게 쳐야 주석처리된다
## 1. 데이터베이스 생성

CREATE DATABASE kant_shop;

## 2. 새로 만든 데이터베이스에 접속 (특정 DB를 사용하겠다.)
\c kant_shop

## 3. 상품 테이블 생성
CREATE TABLE product (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    price INT NOT NULL,
    stock INT NOT NULL
);

## 4. 상품 초기 데이터 입력
INSERT INTO product (name, price, stock) VALUES
('무선 이어폰', 35000, 100), 
('게이밍 마우스', 28000, 85), 
('27인치 모니터', 259000, 15), 
('USB-C 허브', 19900, 200), 
('노트북 거치대', 24000, 7), 
```
### 코드 풀이(AI도움 받기)
```md
위 코드는 PostgreSQL 환경에서 프로젝트를 시작할때 필요한 데이터베이스 환경을 초기화하고 상품데이터를 관리하기 위한 기본 테이블과 샘플 데이터를 세팅하는 스크립트입니다. 

1. 데이터베이스 생성 및 초기화
DROP DATABASE IF EXISTS kant_shop;
ㄴ 만약 이전에 실수로 만들었거나 남아있는 kant_shop이라는 이름의 데이터베이스가 있다면 먼저 삭제(초기화)합니다. IF EXISTS를 붙여서 데이터베이스가 존재하지 않아도 에러가 나지 않고 안전하게 넘어가도록 했습니다. 

CREATE DATABASE kant_shop;
ㄴ kant_shop 이라는 이름의 새로운 데이터베이스를 생성합니다. 위 상품들을 담는 곳이 쇼핑몰이라면 쇼핑몰 전체 데이터를 담을 독립된 공간을 만드는 과정입니다. 

2. 데이터베이스 접속
\c kant_shop
ㄴ PostgreSQL의 대화형 터미널(psql)명령어인 \c는 "지금부터 작업할 데이터베이스를 지정(연결)한다"는 뜻입니다. 방금 만든 kant_shop 데이터베이스로 접속을 전환해야 다음에 실행하는 테이블 생성이나 데이터 입력 명령어가 올바른 데이터베이스 안에서 수행됩니다. 

3. 상품 테이블 생성
CREATE TABLE product (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL, 
    price INT NOT NULL,
    stock INT NOT NULL
);
ㄴ 데이터를 체계적으로 저장하기 위해 product라는 이름의 표(테이블)를 정의한것입니다 
id SERIAL PRIMARY KEY
ㄴ 각 상품을 고유하게 식별하는 기본키(Primary Key)입니다. SERIAL을 사용하여 데이터를 추가할 때마다 번호가 1씩 자동으로 증가 하므로 개발자가 직접 번호를 관리할 필요가 없어 편리합니다. 
name VARCHAR(100) NOT NULL
ㄴ 상품 이름입니다. 최대 100글자까지 저장할 수 있는 가변 길이 문자열(VARCHAR)을 사용했고 NOT NULL을 붙여 이름이 없는 상품은 등록되지 않도록 강제했습니다. 
price INT NOT NULL
ㄴ 상품 가격입니다. 정수형(INT)으로 처리하며 이 역시 NOT NULL을 통해 가격이 누락되지 않도록 했습니다. 
stock INT NOT NULL
ㄴ 상품의 재고 수량입니다. 정수형(INT)을 사용하고 NOT NULL로 재고 정보 입력이 필수임을 지정했습니다. 

4. 상품 초기 데이터 입력 
INSERT INTO product (name, price, stock) VALUES
('무선 이어폰', 35000, 100), 
('게이밍 마우스', 28000, 85),
('27인치 모니터', 259000, 15),
('USB-C 허브', 19900, 200),
('노트북 거치대', 24000, 7);
ㄴ 테이블만 만들고 나면 데이터가 텅 비어 있어서 쇼핑몰 기능을 테스트하거나 조회(SELECT)해볼때 불편합니다
따라서 개발 초기 단계에서 바로 화면이나 API를 테스트해볼 수 있도록 현실감 있는 샘플 상품 데이터 5개를 미리 채워 넣은 것입니다(id는 SERIAL이므로 자동으로 1부터 5까지 순서대로 부여됩니다)
```

## 03 docker 볼륨에 대해서
### 01 볼륨은 왜 쓰는가? 
```MD
컨테이너가 생성하고 사용하는 데이터를 컨테이너 내부가 아닌 호스트(Host) 컴퓨터의 특정 공간에 안전하게 저장하도록 돕는 기능입니다

보통 도커 컨테이너는 기본적으로 일회성입니다. 컨테이너가 삭제되거나 재시작되면 그 안에 있던 데이터도 전부 사라져버립니다. 근데 이때 볼륨은 "데이터는 컨테이너와 별개로 안전한 곳에 따로 보관하자" 라는 개념입니다. 
```
### 02 볼륨을 어떻게 쓰는가? 
```md
1) 직접 볼륨을 생성하고 컨테이너에 연결하는 법 
2) 컨테이너를 만들 때 볼륨을 자동으로 세팅하는 법 
오늘은 이 두개중에서, 1번만 실습을 해봤습니다. 
```
### 03 볼륨 만들기 
```sh
docker volume create pgdata #pgdata는 만들 볼륨의 이름이니 임의로 목적에 맞게 작성가능함. 
```
### 04 생성된 볼륨의 상세 구성 정보, 저장위치 확인하기
```sh
docker volume inspect pgdata #pgdata는 만들 볼륨의 이름이니 임의로 목적에 맞게 작성가능함. 
```
#### 위와 같이 입력하면 나오는 화면:

### 05 만든 볼륨을 기존 컨테이너에 연결하기 
```sh
docker run -d --name my-pg -e POSTGRES_PASSWORD=admin1234 -p 5432:5432 -v pgdata:/var/lib/postgresql postgres:18
```
#### 코드 해설(AI도움)
```md
PostgreSQL18 데이터베이스 컨테이너를 백그라운드에서 실행하고, 비밀번호와 포트, 그리고 데이터가 안전하게 보존되는 볼륨까지 한번에 설정하는 명령어입니다. 

컨테이너 이름은 my-pg, 관리자 비밀번호는 admin1234, 내 컴퓨터의 5432번 포트를 컨테이너의 5432번 포트와 연결, 데이터가 날아가지 않도록  pgdata라는 볼륨에 영구 저장하는것. 
```
그러면 이제 연결한 컨테이너를 삭제하고 새로 생성을 해도 볼륨에 저장된 데이터는 그대로 불러와져야한다. 

## 04 docker 컴포즈에 대해서  
### 01 컴포즈는 왜 알아야하는가? 
```md
지금까지 도커 명령어를 보면 굉장히 어렵다. 그래서 도커 컴포즈 업이라는 명령어가 있는데 이건 복잡하게 쓰지 않고 한줄로 처리하는 명령어다. 

긴 명령어의 지옥에서 탈출, 명령어 한번으로 전체 시스템 제어, 컨테이너끼리 알아서 통신하는 네트워크 환경, 코드처럼 관리하고 협업하기 편한 장점들이 있다. 

docker run이 수동으로 하나씩 조립하는 망치라면, docker compose는 설계도(야몰파일에 저장된것)를 보고 한번에 뚝딱 공장을 지어주는 스마트한 자동화 로봇이라고 볼 수 있다. 
```
### 02 컴포즈를 어떻게 사용하는가(1)? 
**일단 야몰(yml)파일을 만들자**
compose.yaml 이런식으로 만들어줍니다. 

그리고 yml 파일에 설계도를 적어줍니다. 

```sh
services:                 # 실행할 컨테이너(서비스) 목록 — 필수
  서비스이름:              # 예: db, web (직접 정하는 이름)
    image: 이미지:태그      # 사용할 이미지
    container_name: 이름   # 컨테이너 이름 (생략 시 자동 생성)
    environment:           # 환경 변수 (-e)
      KEY: value
    ports:                 # 포트 연결 (-p) — 문자열로 감싸는 것을 권장
      - "호스트:컨테이너"
    volumes:               # 볼륨 연결 (-v)
      - 볼륨이름:컨테이너경로

volumes:                  # 사용할 볼륨 선언 (최상위)
  볼륨이름: 
```
위에 보는것이 컴포즈 야몰을 작성하는 양식입니다
그리고 이것을 우리는 아래와 같이 적었습니다 
```sh
services:                 # 실행할 컨테이너(서비스) 목록 — 필수
  db:              # 예: db, web (직접 정하는 이름)
    image: postgres:18      # 사용할 이미지
    container_name: kant-pg   # 컨테이너 이름 (생략 시 자동 생성)
    environment:           # 환경 변수 (-e)
      POSTGRES_PASSWORD: admin1234
    ports:                 # 포트 연결 (-p) — 문자열로 감싸는 것을 권장
      - "5433:5432"
    volumes:               # 볼륨 연결 (-v)
      - pgdata:/var/lib/postgresql

volumes:                  # 사용할 볼륨 선언 (최상위)
  pgdata:
    external: true
```
#### 코드 해설(AI도움)
```md
1) 왜 이런 yml파일을 따로 만들어주는가? 
파일 하나에 기록(문서화)해 두면 단 한 줄의 명령어(docker compose up -d)만으로 복잡한 옵션 설정 없이 일일이 타이핑할 필요 없이 원하는 환경을 일괄 생성, 실행, 관리할 수 있습니다. 또한 다른 사람과 환경을 공유하거나 재사용할 때 매우 편리합니다.

2) 이 파일에서 쓰는 코드는 어떤 문법인가? 
YAML(YAML Ain't Markup Language) 문법으로 작성되었습니다. 
이는 사람이 읽고 쓰기 가장 편하도록 설계된 데이터 직렬화언어입니다. 주로 프로그램의 설정파일이나 데이터 전송에 널리 사용되며 가독성이 높고 구조가 직관적입니다. 

3) 이 파일의 코드를 작성하는데에 있어서 들여쓰기의 중요성? 
- 일단 YAML문법은 파이썬처럼 들여쓰기가 구조를 결정하는 핵심문법 요소입니다. 
- 대괄호, 중괄호가 없이 들여쓰기의 깊이를 통해 상위 항목과 하위 항목(부모-자식관계)을 구분합니다. 
- 예를 들어 db: 는 services: 하위에 들여쓰기 되어 있으므로 services라는 큰 카테고리 안에 속한 서비스 중 하나임을 의미합니다 
- 참고로 여기서는 탭으로 들여쓰기를 하면 에러가 발생할 수 있어 반드시 스페이스로 띄어쓰기를 사용해야 합니다
- 들여쓰기 칸 수가 어긋나면 도커 컴포넌트가 파일의 구조를 잘못 해석해 실행 오류를 뿜어냅니다 보통 2칸 또는 4칸 공백을 일관되게 유지하는것이 규칙입니다. 
4) 위에 작성된 YAML문법 코드의 요약
나는 postgres:18 버전을 사용해 kant-pg라는 이름의 데이터베이스 컨테이너를 띄울 거야. 비밀번호는 admin1234로 하고 내 컴퓨터의 5433번 포트를 접속하면 컨테이너 내부 5432번과 연결해줘 그리고 데이터는 미리 만들어둔 외부 볼륨 pgdata에 안전하게 저장해줘
```

```md
> 나만 됐었던 '컴퓨터'가 이제는 우리 팀이 모두 되는 '컴퓨터'가 된다. 그리고 모든게 다 빠르게 설정 가능하다.

03 터미널에서 리눅스 OS 이미지받아 구동시키기
> docker run -it --name my-server ubuntu:24.04 bash 
04 터미널에서 nginx 이미지받아 구동시키기 
> docker run -d --name my-webserver -p 8080:80 nginx
05 터미널에서 mysql 이미지받아 구동시키기
> docker run -d --name my-sql -e MYSQL_ROOT_PASSWORD=admin1234 -p 3306:3306 mysql:8.4
> docker exec -it my-sql mysql -u root -p
06 터미널에서 postgres 이미지받아 구동시키기
```

```md
애당초, 파이썬 기본 역량을 기르는 기간이 기초만해도 최소1개월부터 2개월, 중급과정은 최대 4개월, 실무과정은 최대 1년이상은 해야한다고 하니까, 어차피 이걸 3주만에 마스터를 한다는건 어려웠고, 이제 2개월이상은 꾸준히 파이썬 수업을 안한다고 해도 매일매일 파이썬 기본기를 계속 반복공부를 해보면서 파이썬 기본 역량을 길러 나가기 위해 노력을 많이 해야겠다고느꼈습니다. 

- 대책: 현재, 굿모닝커밋 프로젝트, 굿나잇커밋 프로젝트, 주말커밋 프로젝트 등 아침부터 저녁까지 그리고 주말에도 반복적으로 프로젝트 아이디어를 생각해보고 여전히 스스로 생각은 못해서 AI에게 코드를 달라고 한다음에 그걸 타이핑 하는 수준이긴하지만, 그 해당 전공의 서적을 5권이상을 읽고 공부하기만 해도 그 분야에 대해 전문가가 될 수 있다고도 하니, 물론 스스로 생각하는 훈련도 해야겠지만 지금 당장은 파이썬 이론 공부와 병행하며 AI가 만들어준 코드를 계속 쳐보는식으로 파이썬 기본기 역량을 올려봐야겠다고 생각했습니다. 
```
