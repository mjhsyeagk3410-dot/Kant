## 01 CASE
```md
CASE 구문은 쿼리 안에서 IF-THEN-ELSE처럼 조건에 따라 다른 값을 반환하는 조건부 표현식 
```
### 기본 문법(조건식 비교)
    ```sh
    SELECT
        CASE
            WHEN 조건1 THEN 결과1
            WHEN 조건2 THEN RUFRHK2
            ELSE 기본값
        END AS 별칭
    FROM 테이블명;
    ```
### 기본 문법(값 일치 비교)
```sh
SELECT
    CASE 컬럼명
        WHEN 값1 THEN 결과1
        WHEN 값2 THEN 결과2
        ELSE 기본값
    END AS 별칭
FROM 테이블명;
```
#### 자주 쓰는 활용 예시
```sh
# 조건문 집계(피벗, 카운트)
SELECT 
    COUNT(CASE WHEN status = 'delivered' THEN 1 END) AS delivered_cnt,
    SUM(CASE WHEN status = 'delivered' THEN quantity ELSE 0 END) AS delivered_qty
FROM orders;
```
### WHEN
```md
주로 SQL의 CASH WHEN 구문에서 조건을 지정할때 쓰이며 MyBatis 동적 쿼리의 <when> 태그로도 사용 
```
#### 기본 문법 
```sh
SELECT
    name,
    CASE
        WHEN score >= 90 THEN 'A'
        WHEN score >= 80 THEN 'B'
        ELSE 'C'
    END AS grade
FROM students;
```
### THEN
```md
THEN은 CASE 조건문의 일부로 사용되며 특정 조건이 참일때 어떤 값을 반환할지 지정하는 구문이다. 
```
#### 기본 문법
```md
CASE
    WHEN [조건1] THEN [조건1이 참일 때 반환할 값]
    WHEN [조건2] THEN [조건2가 참일 때 반환할 값]
    ELSE [모든 조건에 해당하지 않을 때 반환할 값]
END
```
#### 사용 예시
```sh
SELECT
    name,
    score,
    CASE
        WHEN score >= 90 THEN 'A'
        WHEN score >= 80 THEN 'B'
        WHEN score >= 70 THEN 'C'
        ELSE 'F'
    END AS grade
FROM student_scores;
```
### ELSE
```md
주로 SELECT 절 안의 CASE WHEN과 프로시저, 스크립트의 IF, ELSE 두 방식으로 씀. 
ELSE는 조건이 맞지 않을때 실행할 기본값이나 대체 구문을 지정. 
```
