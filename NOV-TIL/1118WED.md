## 01 CASE
```md
CASE 구문은 쿼리 안에서 IF-THEN-ELSE처럼 조건에 따라 다른 값을 반환하는 조건부 표현식 
```
### 기본 문법(조건식 비교)
    ```sh
    SELECT
        CASE
            WHEN 조건1 THEN 결과1
            WHEN 조건2 THEN RUFRHK2
            ELSE 기본값
        END AS 별칭
    FROM 테이블명;
    ```
### 기본 문법(값 일치 비교)
```sh
SELECT
    CASE 컬럼명
        WHEN 값1 THEN 결과1
        WHEN 값2 THEN 결과2
        ELSE 기본값
    END AS 별칭
FROM 테이블명;
```
#### 자주 쓰는 활용 예시
```sh
# 조건문 집계(피벗, 카운트)
SELECT 
    COUNT(CASE WHEN status = 'delivered' THEN 1 END) AS delivered_cnt,
    SUM(CASE WHEN status = 'delivered' THEN quantity ELSE 0 END) AS delivered_qty
FROM orders;
```
### WHEN
```md
주로 SQL의 CASH WHEN 구문에서 조건을 지정할때 쓰이며 MyBatis 동적 쿼리의 <when> 태그로도 사용 
```
#### 기본 문법 
```sh
SELECT
    name,
    CASE
        WHEN score >= 90 THEN 'A'
        WHEN score >= 80 THEN 'B'
        ELSE 'C'
    END AS grade
FROM students;
```
### THEN
```md
THEN은 CASE 조건문의 일부로 사용되며 특정 조건이 참일때 어떤 값을 반환할지 지정하는 구문이다. 
```
#### 기본 문법
```md
CASE
    WHEN [조건1] THEN [조건1이 참일 때 반환할 값]
    WHEN [조건2] THEN [조건2가 참일 때 반환할 값]
    ELSE [모든 조건에 해당하지 않을 때 반환할 값]
END
```
#### 사용 예시
```sh
SELECT
    name,
    score,
    CASE
        WHEN score >= 90 THEN 'A'
        WHEN score >= 80 THEN 'B'
        WHEN score >= 70 THEN 'C'
        ELSE 'F'
    END AS grade
FROM student_scores;
```
### ELSE
```md
주로 SELECT 절 안의 CASE WHEN과 프로시저, 스크립트의 IF, ELSE 두 방식으로 씀. 
ELSE는 조건이 맞지 않을때 실행할 기본값이나 대체 구문을 지정. 
```
---
### END
```md
CASE 표현식 종료 또는 BEGIN 블록 종료에 사용합니다. 
```
## 02 정렬
### ORDER BY
```md
ORDER BY절은 SELECT로 조회한 결과를 특정 기준에 따라 오름차순(ASC)또는 내림차순(DESC)으로 정렬할때 사용. 정렬 기준은 기정하지 않으면 기본값인 ASC(오름차순)가 적용되며 보통 쿼리의 가장 마지막에 위치 
```
### DESC
```md
DESC는 쓰이는 위치에 따라 내림차순 정렬 또는 테이블 구조조회를 함. 

ORDER BY절에서는 내림차순 정렬 
(단독으로 쓸때는 테이블 구조 조회할때 씀)
```
## 03 집계함수
```md
여러 행의 값을 계산해 하나의 요약된 결과값으로 반환하는 SQL 함수. 보통 GROUP BY와 함께 그룹별 통계를 구할때 사용 
```
### MIN/MAX
```md
min은 최소값, max는 최댓값을 구하며 
min(컬럼명) / max(컬럼명) 이렇게 씀. 
숫자뿐 아니라 문자열, 날짜에도 쓸 수 있음 
```
### SUM
```md
숫자형 컬럼의 합계를 구함 (null 제외)
```
### AVG
```md
숫자형 컬럼의 평균을 구함 (null 제외) 
```
## 04 수치가공 
```md
SQL 쿼리에서 숫자 데이터를 원하는 형태로 계산하거나 변환하는 수치 가공은 주로 산술 연산자와 내장 수치 함수를 조합하여 처리. 
```
### ROUND
```md
지정한 자릿수까지 반올림한다. 자릿수를 생략하거나 0을 넣으면 정수로 반올림함
```
## 05 그룹 필터링 
```md
데이터를 그룹화하고 조건에 맞게 필터링 할 때는 GROUP BY절과 HAVING절을 함께 사용. 
개별 행을 먼저 거를 때는 WHERE절을 쓰고, 그룹화된 집계 결과를 거를 때는 HAVING절을 사용. 
```
### HAVING
```md
GROUP BY로 묶인 그룹 결과에 조건을 걸어 필터링할때 사용 (그룹 단위 필터링)
COUNT, SUM, AVG, MAX, MIN같은 집계 함수 결과로 조건을 지정할때 주로 씀 
```
## 06 데이터 결합
```md
SQL에서 쿼리나 데이터를 결합하는 방법은 크게 가로 결합(열 기준)과 세로 결합(행 기준)으로 나뉜다. 
``` 
### UNION
```md
세로 결합. 집합 연산자(행 추가, 비교) 
여러 SELECT 쿼리 결과를 위아래로 이어 붙이거나 비교. 
열 개수, 순서, 데이터 타입이 맞아야 함 
```
#### UNION ALL
```md
중복을 제거하지 않고 모든 결과를 그대로 합침. 정렬, 중복 제거 비용이 없이 빠름 
```
#### UNION
```md
결과를 합친 뒤 중복 행을 제거 
```
#### INTERSECT/EXCEPT(MINUS)
```md
두 쿼리 결과의 교집합 또는 차집합을 구함 
```
### JOIN
```md
가로 결합. 열 확장. 
공통 컬럼을 기준으로 두 개 이상의 테이블이나 쿼리 결과를 옆으로 붙인다. 
```
#### INNER JOIN
```md
양쪽으로 조건이 일치하는 행만 반환
```
#### LEFT JOIN / RIGHT JOIN
```md
한쪽 테이블의 모든 행을 유지하고 반대쪽에서 일치하는 값만 붙임
```
#### FULL OUTER JOIN
```md
양쪽 테이블의 모든 행을 포함. (일부 DB는 LEFT JOIN과 RIGHT JOIN을 UNION으로 조합해 구현) 
```
## 07 서브쿼리
```md
SQL쿼리 안에 중첩된 또 다른 SELECT문으로 바깥쪽 쿼리를 메인 쿼리, 안쪽 쿼리를 서브쿼리라고 부릅니다. 복잡한 조건 필터링이나 중간 집계 결과를 만들때 사용 
```
### 스칼라 서브쿼리(SELECT절)
```md
행마다 단일 값(1행 1열)을 반환하며 컬럼처럼 출력할때 씀
```
### 인라인 뷰(FROM절)
```md
결과를 임시 테이블처럼 다루며 보통 별칭(AS)을 지정 
```
### 중첩 서브쿼리(WHERE, HAVING 절)
```md
메인 쿼리의 조건을 걸 때 쓰며, 반환 행 수에 따라 연산자를 구분 
```
