### 프로젝트에서 코드륾 만들때 주석을 잘 달아야한다
```md
왜? 주석은 미래에 이 코드를 볼 나 자신을 위한것이고 나와 함께하는 팀원들을 위한것이다. 

근데 주의할 점도 있다. 
뻔한 일을 다시 한 번 풀어쓰는 주석은 의미없다. 
코드를 고쳤다면 주석도 고쳐야한다. 틀린 주석은 없는 주석보다 나쁘다. 
코드를 주석 처리한채 방치하지 말자 필요없으면 지우자 어차피 버전관리가 기억한다. 

좋은 주석이라는것은, '왜?'를 설명한다.
어떤 제약때문에, 어떤 우회책을 썼고, 이런 코드만 봐서는 알 수 없는 결정같은것들도 쓰면 좋다. 
```
### enumerate() 에 대해서 알아보자 
```sh
# 튜터님이 가위바위보 게임만들때 승패 판결목록 표시를 위해 쓴 enumerate()
def show_records(recodes):
    print("\n[판별 승패 목록]")
    # "1판 : 가위 vs 바위 => 패배
    # "2판 : 가위 vs 바위 => 패배
    # "3판 : 가위 vs 바위 => 패배
    for number, record in enumerate(recodes, start=1):
        print(f"{number}판: {record}")
```
#### 왜 썼는가? 
```md
반복 횟수(몇 판째인지)와 리스트 안의 문자열 데이터를 동시에 추적해야 할 때, 코드를 길게 쓰고 수동으로 변수(number += 1)를 조작할 필요 없이 가장 파이썬스럽고 깔끔하게 해결하기 위해 사용한다
```
### 디버깅은 왜 해여하는걸까?
```md
디버깅은 개발자의 실력을 결정짓는 핵심 역량이며 단순한 에러 수정이 아니라 코드를 이해하고 문제의 원인을 분석하는 모든 과정이다. 

디버깅은 단순한 기술이 아니라 개발자의 사고력과 문제해결 능력이 드러나는 영역이며 디버깅을 잘하면 코드 품질이 올라가고 실무에서도 신뢰받는 개발자가 되며 코드는 작성보다 수정이 더 많다 곧 디버깅은 개발의 반이다 

디버깅을 잘한다는 것은, 코드 흐름을 머리속에 그릴 수 있어야한다. 또한 에러 메시지를 무시하지 말고 의미를 해석 할 수 있어야 한다. vscode외에도 다양한 디버깅 도구를 익히고 활용해 볼 수 있어야 한다. 
```
### 부모클래스와 자식클래스, 여기에서 말하는 상속에 대해서 알아보자 
```sh
# 부모 클래스
class Animal:
    # 공통 기능
    def breathe(self):
        print("숨을 쉽니다.")
    def sound(self):
        print("소리를 냅니다.")
```
이렇게 우리가 알고있는 클래스의 모습이 만들어질때, 만약 아래와 같이 코드를 치게 되면 이 클래스는 '부모 클래스'가 된다

```sh
# 부모클래스에게 상속받는 자식 클래스
class Dog(Animal): # 자식클래스를 적고 괄호안에 부모클래스를 적는다. 
    # 상속받은 클래스에서만 있는 고유 기능
    def bark(self):
        print("멍멍")

# 인스턴스 생성
dog1 = Dog()
dog1.breathe() # 부모클래스로부터 물려받은 메서드를 그대로 사용할 수 있다
dog1.bark() # 자식클래스의 고유기능
```
여기서 또 하나 알아 볼 수 있는것은, 만약 고양이라는 자식클래스를 만들고, 고양이는 '야옹'을 하게 만들고싶을때, 메소드 오버라이팅이라는것을 쓰게됩니다

```sh
# 메소드 오버라이팅(Method Overriding)
# 부모 클래스에서 정의된 메소드를 수정 또는 추가하는 기능(재정의)

class Cat(Animal):
    def sound(self):
        print("야옹") # 재정의 

nabi = Cat()
nabi.sound()
``` 
위 코드의 원리는 이렇습니다.      
원래대로라면 Animal의 sound을 호출하면 '소리를 냅니다.'가 호출되야합니다. 근데 고양이는 '야옹'을 하게 만들고싶어요. 그래서 자식클래스인 Cat 내부에서 부모와 똑같은 이름(sound)의 메소드를 다시 정의하여 내용을 "야옹"을 출력하도록 바꿨습니다. 이것이 바로 메소드 오버라이팅입니다
