#### A6. (다중 선형회귀 중) 수동으로 계산해보기
- 가중치 5.80222725 2.68100001 0.63219852
- 절편: 17.66
- 수동계산: (4 * 5.80222725) + (7 * 2.68100001) + (30 * 0.63219852) + 17.66

<div align="left">1. 입력값 3개를 각각 변수에 할당</div> 

> x1 = 4<br>
> x2 = 7<br>
> x3 = 30<br>

"앞 셀에서 시험했던 새 학생의 값을 각각 변수에 담음"

<div align="left">2. 학습된 가중치 풀어서 담기</div> 

> w1, w2, w3 = model.coef_

"3개의 가중치가 담긴 배열 model.coef_를 언패킹함" <br>
"첫번째 값(공부 시간 가중치)은 w1에 꺼내 담고"<br>
"두번째 값(수면 시간 가중치)은 w2에 꺼내 담고"<br>
"세번째 값(실습 횟수 가중치)은 w3에 꺼내 담음" 

<div align="left">3. 학습된 절편(model.intercept_)변수에 저장</div> 

> b = model.intercept_

"모델이 학습한 절편 값을 b에 담음"

<div align="left">4. 선형회귀 공식에 대입해 직접 계산</div> 

> result = w1 * x1 + w2 * x2 + w3 * x3 + b

"각 입력값(x1, x2, x2)에 해당 가중치(w1, w2, w3)를 곱해 더함"<br>
"마지막으로 절편(b)을 더해 result에 저장"

<div align="left">5. 직접 계산한 값과 model.predict()결과 비교 출력 </div> 

> print(f"직접 계산: {result:.4f}")<br>
> print(f"predict 계산: {prediction[0]:.4f}")

"직접 공식으로 계산한 result와 앞서 model.predict(new_data)로 구해둔 prediction[0]을 각각 소수점 넷째자리까지 출력해 두 값이 똑같이 나오는지 확인"

#### A14. (다중 선형회귀 중) 학습 돌려보기 

```sh
sgd = SGDRegressor(
    loss="squared_error",       # MSE 손실함수
    learning_rate="constant",   # 일정하게 학습
    eta0=0.01,                  # 초기 학습률
    random_state=42             # 난수 발생 seed 
)

history = []

# 500 Epoch 학습 
for epoch in range(500):
    # 1 Epoch 한번 학습
    sgd.partial_fit(X_train_scaled, y_train)
    pred = sgd.predict(X_train_scaled)

    history.append({
        "epoch": epoch + 1,
        "w1": sgd.coef_[0],
        "w2": sgd.coef_[1],
        "w3": sgd.coef_[2],
        "bias": sgd.intercept_[0],
        "mse": mean_squared_error(y_train, pred)
    })

history_df = pd.DataFrame(history)
history_df.tail()
```

표 형태로 특성(X)과 타겟(y)을 담는 구조

---
### 복수개의 입력 데이터(Multiple Input Features)
```md
DataFrame안에서 쓰는것.<br>
예측에 함께 투입하는 2개 이상의 입력 특성(X)을 의미 .
```
### Describe()
```md
DataFrame에서 호출하는 메서드.<br>
각 열의 개수, 평균, 표준편차, 최솟값, 사분위수, 최댓값 등 기초 통계량을 요약해 분포와 단위를 확인 
```
### 학습 데이터와 테스트 데이터의 분리(Train-Test Split)
```md
from sklearn.model_selection import train_test_split을 먼저 사용하고<br>
X_train, X_test, y_train, y_test = train_test_split를 사용하고<br>
전체 데이터를 학습 데이터와 테스트 데이터로 나누는 작업
``` 
### 학습 데이터 (Training Data)/70% 데이터로 학습 (70% Training Split)
```md
train_test_split 결과 변수에서 사용.<br>
모델이 패턴을 익히는 부분.<br>
모델학습(fit), 평균, 표준편차 계산, Epoch반복의 입력이 되야함.
```
### 테스트 데이터/학습하지 않은 데이터(Test Data/Unseen Data)
```md
train_test_split로 떼어 둔 미학습 데이터<br>
전처리 과정에서 학습 데이터 기준으로 계산된 스케일러(transform)를 적용한 뒤 예측(predict)과 모델 평가에 사용
```
### 전처리 과정(Data Preprocessing)
```md
학습 데이터와 테스트 데이터의 분리 이후<br>
모델 학습 전에 거치는 정돈 단계로 특성 스케일링이 대표적.
```
### 특성 스케일링 (Feature Scaling)
```md
특성 간 값 범위를 맞추는 작업으로 표준화 객체(StandardScaler)로 구현. 경사하강법(SGDRegressor)에서 기울기 업데이트를 안정화하는데 도움을 줌 
```
### 표준화 객체(StandardScaler)
```md
특성 스케일링을 수행하는 객체. 학습 데이터에 fit해 평균, 표준편차 계산을 마친 뒤 학습/테스트
```
### 선형회귀(Linear Regression)
```md
입력과 출력의 선형 관계를 찾는 모델 계열로 입력이 2개 이상이면 다중 선형회귀가 됨 
```
### 다중 선형회귀(Multiple Linear Regression)
```md
복수개의 입력 데이터를 받아 가중치, 절편을 학습하는 선형회귀 모델
``` 
### 모델 생성(Model Instantiation) 
```md
모델 학습 전에 모델 클래스로부터 인스턴스를 만드는 단계
```
### 모델 학습? 
```md
생성된 모델에 학습 데이터를 넣어 가중치, 절편을 찾아내는 과정
```
### 가중치, 절편? 
```md
모델 학습 결과로 얻어지는 선형식의 파라미터.<br>
복수개의 입력 데이터 각 열마다 가중치가 하나씩 생기고<br>
기준선 역할로 절편이 생김. <br>
예측 계산에 직접 쓰이며 가로바 막대 그래프로 시각화 할 수 있음 
```
### 가로바 막대 그래프? 
```md
학습된 가중치크기를 특성이름과 함께 비교할 때 쓰는 시각화 방식
```
### 경사하강법? 
```md
오차를 줄이는 방향으로 파라미터(가중치, 절편)를 조금씩 이동시키는 최적화 방법. SGDRegressor의 학습 원리. 손실곡선이 내려가는 방향으로 진행 
```
### SGDRegressor
```md
경사하강법으로 학습하는 선형회귀 모델로 모델생성시 seed와 eroph관련 설정을 함께 다룸 
```
### Epoch
```md
SGDRegressor등에서 학습 데이터 전체를 한 번 순회하는 단위로 반복 횟수가 늘어나면서 손실곡선의 변화가 기록됨
```
### 예측(Prediction)
```md
학습된 모델(또는 가중치, 절편)로 테스트 데이터의 입력에 대한 출력값을 계산
``` 
### 오차(Error/Residual) 
```md
실제 정답과 예측 결과의 차이로 MAE, MSE 계산의 재료가 됨 
```
### 모델 평가(Model Evaluation)
```md
예측값과 실제값 사이의 오차를 MAE, MSE, R2 score로 수치화해 성능을 판단하는 단계
```
