## 02 ERD 란 무엇인가
```md
[개념]
ERD는 Entity-Relationship Diagram의 약자다. 
E-R Model이라고도 한다. 이는 객체-관계 모델로써, 세상의 사물을 개체(Entity)와 개체 간의 관계(Relationship)로 표현하는 데이터 모델링 방식으로 개념적 데이터 모델링 단계에서 사용 

[구성요소] 
Entity: 엔터티는 정의 가능한 사물 또는 개념
Attribute: 엔터티를 구성하고 있는 구성요소
Relationship: 엔터티간의 관계를 의미하며, 두 엔터티간에 선을 긋고 관계 명칭을 기록함

[카디널리티]
관계가 존재하는 두 엔터티 사이에 한 엔터티에서 다른 엔터티 몇 개의 개체와 대응되는지 제약조건을 표기하기 위해 선을 그어 표현

[카디널리티 종류]
One to One : 1대 1 대응(1:1)
One to Many : 1대 다 대응(1:N)
Many to Many : 다 대 다 대응(M:N)

[vs code에서 보는법]
1. 먼저 DBCode 라는 확장프로그램 설치 후 데이터베이스가 저장된 커넥션을 연결
2. DBCode 아이콘 눌러서 연결된 데이터베이스 클릭하고 Schemas-Public-Tables를 누르고 Tables에서 마우스 오른쪽버튼 클릭한 후 Entity Relationship Diagram을 선택하면 ERD를 볼 수 있음 
```
## 03 LIMIT란 무엇인가
```md
쿼리 결과로 반환하는 행(Row)의 개수를 제한하는것 
```
### 주요 사용 예시
```sh
## 상위 5개 데이터만 조회하기
SELECT * FROM users LIMIT 5;
```
```sh
## 특정 조건으로 정렬 후 상위 N개 조회
## 급여가 가장 높은 직원 3명 조회 
SELECT name, salary
FROM employees
ORDER BY salary DESC
LIMIT 3;
```
```sh
# 페이징 구현하기 
# 1페이지: 처음부터 10개 조회 (OFFSET 0은 생략 가능)
SELECT * FROM posts ORDER BY id DESC LIMIT 10 OFFSET 0;

# 2페이지: 앞의 10개를 건너뛰고 그다음 10개 조회 
SELECT * FROM posts ORDER BY id DESC LIMIT 10 OFFSTE 10;
```
## 04 AS란 무엇인가
```md
열(Column)이나 테이블(Table)에 임시 이름(별칭, Alias)을 부여할때 사용하는 SQL 키워드 

그럴 필요가? 긴 필드명이나 연산 결과에 직관적인 이름을 붙여 가독성을 높인다. 
```
### 쓰는법
#### 컬럼에 별칭 부여
```sh
SELECT name AS 이름, age AS 나이
FROM people;
```
#### 테이블에 별칭 부여
```sh
SELECT t1.course_id, t2.dept_name
FROM teaches AS t1
JOIN instructor AS t2 ON t1.id = t2.id;
```
## 05 DISTINCT란 무엇인가 
```md
조회 결과에서 중복된 데이터를 제거하고 고유한 값들만 추출할때 사용한다
```
### 기본문법
#### 단일 컬럼 중복 제거
```sh
SELECT DISTINCT 컬럼명
FROM 테이블명;
```
#### 다중 컬럼 중복 제거
```sh
SELECT DISTINCT 컬럼1, 컬럼2
FROM 테이블명;
```
## 06 SQL문에서 비교연산 사용하기 
```md
일단 SQL 쿼리문에서도 비교 연산자 사용이 가능하다

비교연산자는 WHERE 절에서 주로 사용한다
특정 조건에 맞는 데이터를 필터링할때 슨다 
```
### 종류
```md
= 같다
<> 또는 != 같지 않다
'>' 보다 크다
'<' 보다 작다
'>=' 크거나 같다
'<=' 작거나 같다
```
### 활용법
```sh
# 나이가 30인 사람 조회
SELECT * FROM users WHERE age = 30;

# 나이가 30이 아닌 사람 조회
SELECT * FROM users WHERE age <> 30;
SELECT * FROM users where age != 30;

# 급여가 5000 초과인 사람 조회 
SELECT * FROM employees WHERE salary > 5000;

# 급여가 3000 미만인 사람 조회 
SELECT * FROM employees WHERE salary < 3000;

# 점수가 80 이상인 사람 조회 
SELECT * FROM students WHERE score >= 80;
```
### 함께 자주 쓰이는 범위, 목록 연산자
```sh
# A이상 B이하의 범위를 조회 
SELECT * FROM employees WHERE salary BETWEEN 3000 AND 5000;

# IN (A, B, C) 목록 중 하나라도 일치하는 값을 조회 
SELECT * FROM users WHERE city IN ('Seoul', 'Busan');
```
## 07 SQL문에서 한글 문자열 쓰기 
```md
쓸 수 있다. 근데 기본적으로 작은 따옴표로 감싸야하며, 데이터베이스 종류나 인코딩 설정에 따라 N 접두사를 붙여야 글자가 깨지지 않는다. 
```
### 기본 작성법
```sh
# 데이터 조회
SELECT * FROM users WHERE name = '홍길동';

# 부분 일치 검색
SELECT * FROM products WHERE title LIKE '%노트북%';

# 데이터 삽입 
INSERT INTO users (name, city) VALUES ('김철수', '서울');
```
### MS SQL Servel 사용할때는 이렇게
```sh
SELECT * FROM users WHERE name = N'홍길동';

INSERT INTO users (name, city) VALUES (N'이영희', N'부산');
```
## 08 IS NULL을 쓰는 경우 
```md
특정 칼럼의 값이 NULL(데이터가 없거나 알 수 없는 상태)인지 확인하는 조건 연산자 
```
### 기본문법 및 예제
```sh
# 값이 NULL인 데이터 찾기 
SELECT *
FROM 테이블명
WHERE 컬럼명 IS NULL;

# 값이 NULL이 아닌 데이터 찾기
SELECT *
FROM 테이블명
WHERE 컬럼명 IS NOT NULL; 
```
## 09 COUNT를 쓰는 경우
```md
특정 조건이나 범위에 부합하는 행(Row)의 개수를 구하는 집계 함수
```
### 주요 count 문법과 차이점 
```md
1. COUNT(*)
테이블의 모든 행(Row)의 개수를 센다. 
NULL 값을 가진 행도 포함하여 전체 카운트를 반환. 
예: SELECT COUNT(*) FROM users;

2. COUNT(컬럼명)
지정한 특정 컬럼에 값이 들어있는 행의 개수를 센다
해당 컬럼의 값이 NULL인 경우는 제외하고 카운트
예: SELECT COUNT(email) FROM users;

3. COUNT(DISTINCT 컬럼명)
특정 컬럼의 값 중에서 중복을 제거한 유일한 값의 개수를 셈 
NULL 값은 제외됨
예: SELECT COUNT(DISTINCT country) FROM users;
```
## 10 BETWEEN을 쓰는 경우
```md
BETWEEN 연산자는 특정 범위(시작값과 종료값 사이)에 포함되는 데이터를 조회할때 사용하는 조건문
```
### 기본문법
```sh
SELECT 컬럼명
FROM 테이블명
WHERE 컬럼명 BETWEEN 시작값 AND 종료값;

# 숫자 범위 조회 (나이가 20세 이상, 24세 이하인 경우)
SELECT *
FROM users
WHERE age BETWEEN 20 AND 24;

# 날짜 범위 조회 (특정 기간 동안의 데이터)
SELECT *
FROM orders
WHERE order_date BETWEEN '2026-01-01' AND '2026-01-31';

# 문자열 범위 조회
SELECT *
FROM employees
WHERE emp_name BETWEEN 'A' AND 'C';

# 반대 개념(NOT BETWEEN)
# 범위 외의 데이터를 조회하고 싶을 때는 NOT BETWEEN을 사용

SELECT *
FROM users
WHERE age NOT BETWEEN 20 AND 24; 
```
## 11 IN (1, 5, 10) 이런걸 쓰는 경우
```md
특정 컬럼의 값이 괄호 안에 나열된 목록(1, 5, 10)중 하나라도 일치하는지 확인하는 조건 연산자

여러 개의 OR조건을 간결하게 줄여서 쓸때 주로 사용 
```
### 기본 사용법 및 예시
```sh
SELECT *
FROM users
WHERE id IN (1, 5, 10);

# OR 연산자와의 비교 
SELECT *
FROM users
WHERE id = 1 OR id = 5 OR id = 10;

# 만약 이 숫자를 제외한 나머지 데이터를 조회하고 싶다면
SELECT * FROM users WHERE id NOT IN (1, 5, 10)

# 문자열 비교: 숫자가 아닌 데이터를 찾을 때는 작은따옴표로 감싸줍니다
SELECT * FROM users WHERE status IN ('ACTIVE', 'PENDING');

# 서브쿼리 활용: 괄호 안에 직접 값을 적는 대신, 다른 SELECT 쿼리의 결과를 넣을 수도 있음
SELECT * FROM users WHERE id IN (SELECT user_id FROM orders);
```
## 12 LIKE를 쓰는경우 
```md
WHERE 절에서 특정 문자열 패턴을 검색하고 부분적으로 일치하는 데이터를 찾을때 사용
```
### 기본문법 
```sh
SELECT [컬럼명]
FROM [테이블명] 
WHERE [컬럼명] LIKE [패턴];
```
### 활용방법
```sh
# A로 시작하는 문자열 찾기 
SELECT 컬럼명 FROM 테이블 WHERE 컬럼명 LIKE 'A%'

# A로 끝나는 문자 찾기 
SELECT 컬럼명 FROM 테이블 WHERE 컬럼명 LIKE '%A'

# A를 포함하는 문자 찾기 
SELECT 컬럼명 FROM 테이블 WHERE 컬럼명 LIKE '%A%'

# A로 시작하는 두글자 문자 찾기 
SELECT 컬럼명 FROM 테이블 WHERE 컬럼명 LIKE 'A_'

# 첫번째 문자가 'A'가 아닌 모든 문자열 찾기
SELECT 컬럼명 FROM 테이블 WHERE 컬럼명 LIKE '[^A]'

# 첫번째 문자가 'A'또는 'B'또는 'C'인 문자열 찾기
SELECT 컬럼명 FROM 테이블 WHERE 컬럼명 LIKE '[ABC]'
SELECT 컬럼명 FROM 테이블 WHERE 컬럼명 LIKE '[A-C]'
```
## 13 미니과제 생각하고 제출하기까지
```md
상태: 피곤에 절여진 상태로 과제하는동안 비몽사몽한 상태로 과제를 했는데, 그래도 끝까지 잘 했습니다. 

생각: 원래 SQL 미니 과제1때 냈던 프로젝트로 할려다가 시드파일을 참조해서 만들려고 하니까 여러모로 번거로워서 열심히 씨름을 하다가, 너무 생각해야할게 많다보니까 생각할 정신머리도 정리할 정신머리도 없었다보니, 오고가면서 생각했던 기타레슨생이라는 소재를 사용한다면 스포츠센터와 비교적 알맞게 굴러가지 않을까 생각을 해서 새로운 프로젝트 디렉토리를 만들었고, 그렇게 기타아카데미라는 새로운 디렉토리를 만들고, 이곳에 새로운 데이터베이스를 만들고 테이블을 만들어가면서 내용을 적어나갔습니다. 
물론 여전히 생각해야할게 굉장히 많았다보니 머리가 잘 굴러가지가 않았는데, 일단 SQL파일에다가 적어놓은것을 그대로 시드파일에다가 이름만 바꿔서 기재를 하고 속성과 콜롬들을 적어가면서 완성을 해나갔습니다. 
맞게 제출한건지는 모르겠지만 일단 열심히는 했습니다. 
```
