### 01 딕셔너리 변수 생각하는것
- 일단은 딕셔너리 변수로 해야겠다라는 생각에도 도달하지 못했었습니다. 비슷하게 생각났던건 리스트로 저장해야겠다? 정도였습니다. 그리고 그렇게 저장하는것도 = (가위, 바위, 보) 수준이였지, = {1: "가위", 2: "바위", 3: "보"} 이렇게 만들어야겠다라는 생각을 못했었습니다. 
- 딕셔너리 배운 것 복기해보기
```md
- {"키": "값"} 의 쌍으로 이루어진 자료구조다 {}는 중괄호.
- "키"는 중복이 불가능하다, "값"은 중복이 가능하다 
- "값"에는 숫자, 문자열, 리스트, 새로운 딕셔너리도 넣을 수 있다. 
- 추가하는 순서를 유지해야한다. 
```

```sh
{"a" : 1}
{"a" : 1, "b" : 1}
print({"a": 1, "b": 1})
```
출력: 
{'a':1, 'b': 1}

**딕셔너리 주요 메서드**
- keys(), values(), items()
코드예제 3
```sh
menu = {"coffee": 4000, "tea": 4500}

# key 목록 조회
print(menu.keys())
# value 목록 조회
print(menu.values())
# items 조회 (키, 값) 튜플 형태로 리턴
print(menu.items())

# 딕셔너리는 인덱스 방식으로 값을 참조 불가 > list로 변환
print(list(menu.keys())[1])

print((menu.values()))
``` 
출력:
```md
dict_keys(['coffee', 'tea'])
dict_values([4000, 4500])
dict_items([('coffee', 4000), ('tea', 4500)])
tea
8500
```

AI에게 부탁한 코드 예문

```md
나는 지금 파이썬을 공부중인데, 파이썬에서 딕셔너리를 최대한으로 사용한 코드를 만들어보고싶어. 딕셔너리의 주요 메서드인 keys(), values(), items()가 모두 다 들어가는것으로 딕셔너리를 최대한으로 활용한 코드 예문을 만들어줘
```
AI가 만들어준 딕셔너리를 최대 활용한 코드 예제
```sh
# **복사붙여넣기 안하고 모두 직접 따라 쳤습니다.**
# 파이썬 딕셔너리를 최대한 활용한 재고 관리 프로그램

# 1. 중첩 딕셔너리(Nested Dictionary) 구조 정의 
# 키: 상품명(str), 값: 상세 정보(dict)
inventory = {
    "apple": {"price": 1200, "quantity": 50, "category": "fruit"},
    "banana": {"price": 800, "quantity": 30, "category": "fruit"},
    "milk": {"price": 2500, "quantity": 20, "category": "dairy"},
    "bread": {"price": 3000, "quantity": 15, "category": "bakery"}
}

print("=== 1. 전체 재고 상세 현황 (tiems() 활용) ===")
# items(): 딕셔너리의 (키, 값) 쌍을 튜플 형태로 변환하여 동시 순회 가능 
for item_name, details in inventory.items():
    print(f"- 상품명: {item_name}")
    print(f"  가격: {details['price']}원 / 수량: {details['quantity']}개 / 분류: {details['category']}")

print("\n=== 2. 등록된 상품 목록 조회 (keys() 활용) ===")
# keys(): 딕셔너리의 모든 키 (상품명)만 추출하여 뷰 객체 반환 
product_names = list(inventory.keys())
print(f"현재 등록된 상품 종류: {product_names}")
print(f"총 상품 가짓수: {len(product_names)}개")

print("\n=== 3. 전체 재고 자산 가치 계산 (values() 활용) ===")
# values(): 딕셔너리의 모든 값(상세 정보 딕셔너리)만 추출 
total_asset = 0
for details in inventory.values():
    # 각 상품의 (가격*수량)을 누적 
    total_asset += details["price"] * details["quantity"]

print(f"창고 내 총 재고 자산 가치:{total_asset:,}원")

print("\n=== 4. 안전한 조회 및 데이터 수정 메서드 활용 ===")
#get() 메서드: 키가 없어도 에러 대신 기본값(None 또는 지정값)을 반환하여 안전함
search_item = "coffee"
result = inventory.get(search_item, "존재하지 않는 상품입니다.")
print(f"'{search_item}' 조회 결과: {result}")

# setdefault() 메서드: 키가 없으면 새로 추가하고, 있으면 기존 값을 반환
# 'egg' 상품이 없으므로 새로 등록됨 
inventory.setdefault("egg", {"price": 6000, "quantity": 25, "category": "dairy"})

# update() 메서드: 기존 딕셔너리 데이터를 수정하거나 병합
# 'apple'의 가격과 수량을 한 번에 업데이트 
inventory["apple"].update({"price": 1300, "quantity": 45})

print("\n=== 5. 딕셔너리 컴프리헨션(Dictionary Comprehension) 활용 ===")
# 재고 수량이 25개 이하인 상품들만 필터링하여 새로운 딕셔너리 생성
low_stock_items = {name: info for name, info in inventory.items() if info["quantity"] <= 25}
print(f"재고 부족 상품 리스트 (25개 이하): {low_stock_items}")

print("\n=== 6. pop()과 del을 통한 데이터 삭제 ===")
# pop(): 특정 키를 삭제하고 그 값(value)을 반환받음 
removed_item = inventory.pop("bread")
print(f"삭제된 상품 정보: {removed_item}")
print(f"최종 남은 재고 키 목록: {list(inventory.keys())}")
```

```md
나는 파이썬 개발 코딩을 공부중인 학생이야.

연산자를 배웠는데, 이 연산자를 최대한 활용한 수학문제를 해결해보는 코드를 만들어보고싶어. 적당한 수학문제를 파이썬 연산자를 모두 사용해볼 수 있는 문제를 찾아봐주고 그것을 풀어내기 위한 파이썬 코드를 만들어줘 
```
AI코드 예제
```sh
# =================================================
# 우주 행정구역 중앙 보안 금고 해독 시뮬레이터
# =================================================

print("=== 보안 금고 해독 프로세스 시작 ===")

# 1 [산술 & 대입 연산자] 자원 및 에너지 효율 계산 
base_power = 1200
booster = 3

# 산술 연산 (*) 및 대립 연산 (=)
efficiency = base_power * booster

# 복합 대립 연산 (**, //, -=)
efficiency **= 1.1 #거듭제곱 연산 및 대입
efficiency //= 10 # 몫 구하기 연산 및 대입 
efficiency -= 15 # 뺄셈 연산 및 대입 

remainder_energy = int(efficiency) % 7 # 나머지 연산(%)
total_score = (int(efficiency) + 50) /2 #덧셈(+), 나눗셈(/)

print(
    f"[1단계 완료] 최종 자원 점수: {total_score} (잔여 에너지 나머지: {remainder_energy})"
)

# 2. [비교 & 논리 연산자] 보안 안전 범위 검증 
min_threshold = 100
max_threshold = 400 

# 비교 연산자 (>=, <=)를 통한 범위 체크
is_stable_range = (total_score >= min_threshold) and (
    total_score <= max_threshold
)
is_emergency = not is_stable_range # 논리 NOT 연산(not)
has_override_privilege = False 

# 논리 OR, AND, NOT 조합 
access_granted = is_stable_range or (
    has_override_privilege and not is_emergency
)
print(f"[2단계 완료] 접근 권한 허용 여부: {access_granted}")

# 3. [비트 연산자] 암호화 비트마스크 변환 
security_mask = 0b1010 #10(진행 제어 비트)
shift_key = 0b0011 #3

bitwise_and = security_mask & 0b1100 # 비트 AND(&)
bitwise_or = security_mask | shift_key # 비트 OR(|)
bitwise_xor = security_mask ^ shift_key # 비트 XOR(^)
bitwise_not = ~security_mask # 비트 NOT(~) -> 부호 반전 및 -1
left_shifted = security_mask << 1 # 좌측 시프트 (<<)
right_shifted = secutiry_mask >> 1 # 우측 시프트 (>>)

print(
    f"[3단계 완료] 비트 연산 결과 - AND: {bitwise_and}, OR: bitwise_or}, XOR: {bitwise_xor}"
)

# 4. [멤버십 & 식별 연산자] 관리자 권한 및 시스템 상태 검증 
autorized_sectors = ["Earth", "Mars", "Europa", "Titan"]
current_sector = "Mars" 

# 멤버십 연산자(in, not in)
is_authorized_location = current_sector in authorized_sectors
is_restricted_zone = "Pluto" not in authorized_sectors

# 식별 연산자(is, is not)
system_status = "ACTIVE"
active_reference = system_status

is_same_status = system_status is active_reference #메모리 객체 일치 확인(is)
is_active_valid = system_status is not None # None이 아님을 확인(is not) 

print(f"[4단계 완료] 구역 인증 성공: {is_authorized_location}")
print(f"[4단계 완료] 시스템 상태 참조 일치: {is_same_status}")

# 최종 금고 개방 판정
final_vault_open = (
    access_granted and is_authorized_location and is_same_status and is_active_valid
)

print("============================================")
if final_vault_open:
    print("보안 금고가 성공적으로 해독되었습니다! 시스템 접근 승인.")
else:
    print("보안 검증 실패, 금고가 잠겨 있습니다.")
print("============================================")
```
