## 02 uv add "psycopg[binary]"와 psycopg 활용 
```md
uv add 명령어는 먼저, 파이썬 프로젝트의 의존성 패키지를 추가하고 관리할때 사용하는 핵심 명령어다. 

psycopg는 파이썬에서 PostgreSQL 데이터베이스에 연결하고 SQL 쿼리를 실행할 수 있게 해주는 대표적인 어댑터(드라이버)다. 

psycopg[binary]는 psycopg3을 미리 컴파일된 바이너리 포함 형태로 설치하는 pip옵션. 로컬에 PostgreSQL 클라이언트 라이브러리나 C컴파일러같은 빌드 도구가 없어도 빠르게 설치하고 사용할 수 있다. 
```

#### 02 강좌 목록 조회 SQL 및 함수 
```sh
LIST_SQL = """
SELECT DISTINCT c.course_id, s.sport_name, c.course_name, c.class_days, c.fee 
FROM courses c
JOIN sports s ON c.sport_id = s.sport_id
LEFT JOIN enrollments e ON c.course_id = e.course_id
                        AND e.enroll_month = %s
ORDER BY c.course_id
"""
```
```md
> """..."""
여러 줄 문자열(멀티라인 스트링)로 SQL쿼리를 작성 
> SELECT DISTINCT ...
중복된 행을 제거하고 courses(c)와 sports(s) 테이블에서 필요한 컬럼들을 선택 
>JOIN sports s ON c.sport_id = s.sport_id
강좌 테이블의 sport_id와 종목 테이블의 sport_id가 일치하는 데이터를 연결
> LEFT JOIN enrollments e ON ... AND e.enroll_month=%s
수강신청(enrollments)테이블을 왼쪽 기준으로 붙이되 enroll_month가 %s(나중에 바인딩될 MONTH 값)인 조건을 함께 걸어 해당 월 강좌 정보를 기준으로 합침(%s는 SQL문자열 포매팅이 아니라 드라이버가 안전하게 값을 넣는 파라미터 플레이스홀더)
>ORDER BY c.course_id
course_id 오름차순으로 결과를 정렬
```
```sh
def list_courses(conn):
    for c in conn.execute(LIST_SQL,(MONTH,)):
        print(f"{c['course_id']:>3} | {c['sport_name']} | {c['course_name']} | {c['class_days']} | {c['fee']:,}원")
```
```md
> def list_courses(conn)
데이터베이스 연결 객체 conn을 인자로 받아 강좌 목록을 출력하는 함숨를 정의 
> conn.execute(LIST_SQL, (MONTH,))
conn의 execute 메서드로 SQL을 실행. 두번째 인자(MONTH,)는 %s자리에 들어갈 값들의 튜플(값이 1개라도 쉼표를 붙여 튜플로 넘기는 것이 psycopg 규칙) 실행 결과는 조회된 행들을 순회할 수 있는 커서/결과 객체를 돌려줌 
> for c in ...
조회된 각 행을 c라는 변수(여기서는 dict_row덕분에 dict형태)로 하나씩 꺼내 반복
> print(f"{c['course_id']:>3})
f-스트링. course_id 값을 3칸 폭으로 오른쪽 정렬(>3)한다 
> {c['fee']:,}원 
f-스트링. 숫자 fee에 천 단위 쉼표를 찍어 출력한다. 
```

#### 04 수강신청 함수
```sh
def enroll(conn, member_id, course_id):
    fee = 0
    conn.execute(
        "INSERT INTO enrollments (member_id, course_id, enroll_month, status, pay_amount)"
        "VALUES (%s, %s, %s, '수강중', %s)",

    )
    print("수강신청 완료되었습니다.")

    conn.execute(
        "INSERT INTO enrollments (member_id, course_id, enroll_month, status, pay_amount)"
        "VALUES (%s, %s, %s, %s, '수강료')",
        (member_id, course_id, MONTH, fee)
    )
    print("수강료입니다.")
```
```md
> def enroll(conn, member_id, course_id)
DB연결 conn, 회원ID, 강좌 ID를 받아 수강신청을 처리하는 함수를 정의. (위쪽의 def enroll(course_name)을 이 정의가 덮어씀)
> fee = 0
수강료 변수 fee를 0으로 초기화 
> conn.execute(...)
INSERT INTO enrollments ... VALUES (%s, %s, %s, '수강중', %s) SQL을 실행한다. 
인접한 두 문자열 리터럴 "INSERT..."와 "VALUES..."는 파이썬에서 자동으로 하나로 이어짐

실습용으로 두 번째 INSERT 구문이 적혀있는데 여기서는 pay_amount 컬럼 자리에 문자열 '수강료'가 들어가고 4번째 %s에 fee가 들어가므로 실제 운영 쿼리라기보다는 수강료 반영 흐름을 연습하기 위한 코드
```

#### 05 진입점 main 및 실행 가드 
```sh
def main():
    with psycopg.connect(DSN, row_factory=dict_row) as conn:
        list_courses(conn) 
        enroll(conn, MEMBER_ID, COURSE_ID)

    if __name__ == "__main__":
    main()
```
```md
> def main()
프로그램의 메인 실행 흐름을 묶어둔 함수 
> psycopg.connect(DSN, row_factory=dict_row)
DSN 정보를 사용해 PostgreSQL DB에 접속하고 결과를 딕셔너리 형태로 받도록 설정한 연결(Connection) 객체를 생성 
> with ... as conn
컨텍스트 매니저(with문). 블록이 끝나면 psycopg 연결 객체가 트랜잭션을 처리하고(예외가 없으면 커밋, 예외가 발생하면 롤백) 연결을 깔끔하게 닫아줌 
> list_courses(conn) 및 enroll(conn, MEMBER_ID, COURSE_ID)
생성된 conn을 넘겨 강좌 목록 조회와 수강신청 함수를 차례로 호출 

> if __name__ == "__main__": main()
파이썬에서 이 파일을 직접 실행했을 때만 __name__이 "__main__"이 되어 main()을 호출. 다른 파일에서 이 모듈을 import만 했을 때는 main()이 자동 실행되지 않도록 막아주는 표준 관용구. 
```

##### 02 PostgreSQL 접속 및 psycopg 실행 오류 
- psycopg.OperationalError (DB 접속 실패)
```md
발생상황: psycopg.connect(DSN, ...) 실행 시 연결을 거부하거나 인증에 실패할 때 발생 

원인: PostgreSQL 서버가 꺼져 있거나 지정한 포트(5430)가 아닌 다른 포트(예; 5432)로 떠 있는 경우 / dbname(guitaracademy), user(postgres), password가 실제 DB 설정과 다른 경우 / Docker나 가상환경으로 띄운 DB의 포트 매핑이 안 된 경우
```
- psycopg.ProgrammingError (파라미터 개수 불일치 / 플레이스홀더 오류)
```md
발생상황: SQL 안의 %s 개수와 두 번째 인자 튜플의 원소 개수가 맞지 않거나 단일 값을 튜플이 아닌 문자열/정수 그대로 넘길 때 발생 

예: %s가 4개인데 튜플에 3개만 넣거나 5개를 넣는 경우
예: (MONTH,)처럼 쉼표를 빼고 (MONTH)로 쓰면 파이썬에서는 문자열 '2026-11'이 되어 글자 수 만큼 쪼개지거나 기대와 다르게 동작 

해결: %s 자릿수와 파라미터 튜플의 길이를 1:1로 맞추고 값이 1개일때는 반드시 (값,)처럼 후행 쉼표를 붙임 
```
- TypeError / keyError (dict_row 미적용 또는 컬럼명 오타)
```md
발생상황: c['course_name']처럼 접근했는데 TypeError: tuple indices must be integers or slices, not str 또는 KeyError: 'course_name'이 뜨는 경우 

원인/해결:
psycopg.connect(DSN)에 row_factory=dict_row를 빠뜨리면 행이 튜플로 반환되어 c['course_name']에서 TypeError가 남. 

SELECT 절에 적은 별칭(alias)이나 컬럼 이름과 c['...']키 이름이 다르면 keyError가 발생 
```
##### 03 SQL쿼리 및 테이블 제약조건 오류 
- psycopg.errors.UndefinedTable / UndefinedColumn
```md
발생상황: courses, sports, enrollments 같은 테이블명이나 course_id, enroll_month, pay_amount같은 컬럼명이 실제 스키마와 다를 때 발생 

해결: psql이나 DB툴에서 \dt로 테이블 목록을 \d 테이블명으로 정확한 컬럼명과 데이터 타입을 먼저 확인하세요 
```
- psycopg.errors.InvalidTextRepresentation (타입 불일치-특히 pay_amount나 ID)
