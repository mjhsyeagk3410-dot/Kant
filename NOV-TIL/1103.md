## 딕셔너리(Dictionaray)
- {"키": "값"} 
- "키" 중복 불가 
- "값" 중복 가능
- 추가하는 순서를 유지 
코드입력
```sh
# {"a" : 1}
# {"a" : 1, "b" : 1}
# print ({"a" : 1, "b" : 2})
print ({"a" : 1, "b" : 1})
```
코드실행
```md
{'a': 1, 'b': 1}
```

### 딕셔너리 주요 메서드 
- keys(), values(), items()
코드 입력
```sh
menu = {"coffee" : 4000, "tea" : 4500}

# Key 목록 조회 
print(menu.keys())
# value 목록 조회 
print(menu.values())
# items 조회 (키, 값) 튜플 형태로 리턴 
print(menu.items())

# 딕셔너리는 인덱스 방식으로 값을 참조 불가 > list로 변환 
print (list(menu.keys())[1])

print ((menu.values()))
```
코드 실행 
```md
dict_keys(['coffee', 'tea'])
dict_values([4000, 4500])
dict_items([('coffee', 4000), ('tea', 4500)])
tea
8500
```
코드 입력
```sh
print ("coffee" in menu) #True
print (4000 in menu) # False

print (4000 in menu.values())#True
```
코드 실행 
```md
True
False
True
```
코드 입력 
```sh
# menu["cake"] 
# cake가 없는 경우 5000으로 반환 
price = menu.get("cake", 5000)
print(price)
# default 값이없는 경우 None
print(menu.get("cake")) #None
print(menu.get("coffee", 0))
print(menu)
```
코드 실행 
```md
5000
None
4000
{'coffee': 4000, 'tea': 4500}
```
### 집합(Set)
- 수학 집합처럼 중복 없고 순서 없는 자료형 
- 중괄호 사용
- set() 함수를 생성 
```sh
grade = set([1, 2, 2, 3, 3, 3])
print (grade) # 중복이 없고, 순서도 없다. 
```
코드 실행 
```md
{1, 2, 3} 
```
코드 입력
```sh
print (type([])) # {} 빈 딕셔너리
print (type(set())) # set() 빈 집합 
print ({1, 2, 2}) # {}를 사용해도 집합이 됨 
```
코드 실행 
```md
<class 'list'>
<class 'set'>
{1, 2}
```
코드 입력 
```sh
s = {1, 2}

# 추가 
s.add(2)
s.add(5)

print(s)

# 삭제 
s.remove(1)
print(s)

# 특정 요소 삭제 
s.discard(2) # 없는 키 삭제할 때도 오류가 없음 
print(s) 
```
코드 실행 
```md
{1, 2, 5}
{2, 5}
{5}
```
코드 입력 
```sh 
set_a = {1, 2, 3}
set_b = {3, 4, 5}

print(set_a $ set_b) # 교집합 
print(set_a | set_b) # 합집합 
print(set_a - set_b) # 차집합
print(3 in set_a) # 포함 여부 
```
코드 실행 
```md
{3}
{1, 2, 3, 4, 5}
{1, 2}
True
```

간단한 실습 
코드 입력 
```sh

for x in range (2, 10): 
    if x == 4: 
        break

        if y == 6:
            break
        print(f"{x} x {y} = {x * y}")
```
