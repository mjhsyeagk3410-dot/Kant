## 클래스 
**01 개념정리** 
```md
- 클래스는 객체(Object)를 생성하는 설계도다
- 클래스를 기반으로 만든 인스턴스(instance)가 있다. 
- 인스턴스(instance) 는 서로 독립적인 속성과 메서드를 가질 수 있다. 
```
**02 클래스 기본 구조** 
```sh
class ClassName:
    def __init__ (self, parameters):
        self.attribute = value
    def method (self, parameters):
        pass 
```
- 항상 먼저, __init__() 메서드를 쓴다.
- init메서드는 생성자로, 객체가 생성될 때 자동 호출된다. 
- self는 인스턴스 자기 자신을 가리킨다. 그래서 메서드 정의 시 항상 첫번째 인자로 작성해야 한다.

results = ["무승부입니다!", "당신의 승리입니다!", "컴퓨터의 승리입니다!"]

# 선택한 내용 출력
print(f"\n나: {options[user_input]}")
print(f"컴퓨터: {options[comp_input]}")

# 핵심 원리: (사용자 - 컴퓨터) % 3 연산으로 승패 판정 인덱스 계산
# 0 -> 무승부, 1 -> 사용자 승리, 2 -> 컴퓨터 승리
result_index = (user_input - comp_input) % 3
