### 03 if문을 활용한 특정 문제의 로직짜고 코드쓰는것
- 일단은 제 경험상 힘들었던 이유는, 아마도 제가 if루프가 어떻게 돌아가는지 잘 이해를 못해서 그런것같습니다. 
- 개념 다시 이해하기 
```md
- if문은 주어진 조건이 참인지 거짓인지 판단하여 프로그램의 흐름을 분기하는 조건문이다. 
- 조건 자리에 불리언 값이 오지 않아도 자체적으로 참과 거짓을 판별함.
- 조건문 뒤에는 반드시 콜론(:)을 붙이며 조건이 참일때 실행될 코드는 들여쓰기(스페이스 4칸)을 해야함. 
- elif(else if)는 앞 if조건이 거짓일때 새로운 조건이 참일때 실행한다. (여러개 사용가능). 곧 앞 if조건이 참이면 이 새로운 조건은 실행되지 않는다. 
- else는 앞선 모든 조건이 거짓일때 마지막으로 실행한다. 곧 if가 true면 여기는 오지않고, elif까지만 True면 여기에 오지 않는다. 
```
코드예제1
```sh
temp = 20

if temp >= 28:
    print("에어컨을 켭니다.")
    print("1시간 후에 자동 종료됩니다.")
print("프로그램 종료")
```
출력값: 프로그램 종료

### 04 while문을 활용한 특정 문제의 로직짜고 코드쓰는것
- 일단은 while문을 써야하나? 라는 생각이였습니다. 사실 while문까지 써야할 일머리가 돌아가지 않아서 핑계이기는 하지만 이 역시 while문을 왜 써야하는지 모르기 때문에 다시 개념부터 잡아야겠다고 생각했습니다. 
- 개념 다시 알아보기 
```md
- 특정조건이 참(True)인동안 코드를 계속 반복해서 실행하고 싶을때 사용하는 제어문 
- for 문은 횟수나 범위가 정해져있다면, while문은 조건이 만족될때까지 끝을 알 수 없는 반복을 수행할때 쓴다. 
```
코드예제1
```sh
num = 1

while num < 3:
    print(f"현재 숫자는 {num}")
    num += 1
```
출력: 
```md
현재 숫자는 1
현재 숫자는 2
```

#숫자 맞추기 게임 
import random # 난수 발생을 위한 모듈 임포트 

# 1~100 사이의 난수 발생
number = random.randint(1, 100)
# 테스트 할때는 (1, 5) 정도만 

# 시도 횟수
try_count = 0

print("="*40)
print("컴퓨터가 1부터 100사이의 숫자를 생성했습니다.")

    if user_input == "q":
        print(f"게임 종료합니다. 정답은 {number}입니다.")
        break

    if not user_input.isdecimal():
        print("숫자만 입력해주세요.")
        continue

    if user_input != 101:
        print("100까지만 입력해주세요.")
        continue

    user_number = int(user_input)
    # 시도 횟수 증가
    try_count += 1 

    # 입력값과 정답을 비교

        print("Up! 더 큰 수 입니다.")
    elif user_number > number:
        print("Down! 더 작은 수 입니다.")
    else:
        print(f"정답입니다. {try_count}회 만에 성공했습니다.")
        break #정답일 경우 무한 루프 탈출

질문: 나는 파이썬 개발 공부를 하고 있는 학생이야. 또 while문을 공부를 하고 있는데, 이  while문을 최대한으로 쓴 코드는 어떻게 생겼는지 코드를 쭉 보고싶어.  이런 코드 예제를 알아봐주고 이런 코드를 만들어줘. 

기왕이면 이 코드에서 위쪽은 for문을 최대한 활용한 코드를 적고, 그 밑으로는 while문을 최대한 활용한 코드를 적어주면 좋을것같아. 왜냐면 for문과 while문의 차이점도 확실하게 학습을 해보고싶어서 

이 코드를 만들어서 보내주면 나는 이걸 따라 쳐보고 왜 이런 코드가 되는걸까? 라는 공부도 해볼 수 있을것같아.

AI에게 받은 코드예제 
```sh
# ===========================================================
# [파트 1] for문 중심의 데이터 처리 및 고정 횟수 반복 
# ===========================================================
print("=== [PART 1] FOR문 활용 영역 (데이터 순회 & 고정 연산) ===")

# 1. 고정된 아이템 리스트와 가격 정보 (for 문을 통한 순회와 포맷팅)
inventory = ["에너지 쉴드", "레이저 건", "체력 회복 키트", "플라즈마 폭탄"]
prices = [1500, 3000, 500, 2000]

print("상점 판매 목록 (for문으로 순회 출력): ")
# enumerate를 사용해 인덱스와 아이템을 동시에 for문으로 순회 
for index, item in enumerate(inventory):
    price = prices[index]
    print(f"   {index + 1}, {item} - 가격: {price} 코인")

print("-" * 50)

# 2. 고정된 횟수만큼 반복하며 자원 총합 계산 (누적 연산)
total_price = 0
# 0부터 3까지(총 4번) 고정된 횟수 반복 
for i in range(len(prices)):
    total_price += prices[i]

print(
    f"모든 아이템을 한 개씩 구매할 때의 총 비용 (for문 누적): {total_price} 코인"
)
print("-" * 50)

# 3. 구구단 형태의 2차원 탐색 (중첩 for문 활용()
print("우주 구역 좌표 스캔 시뮬레이션 (중첩 for문):")
sectors = ["Alpha", "Beta"]
levels = [1, 2, 3] 

# 바깥쪽 for문이 구역을 돌고, 왼쪽 for문이 레벨을 돎(총 2 * 3 = 6번 반복) 
for sector in sectors:
    for level in levels:
        print(f" -> 탐색 중: 구역 [{sector}] - 난이도 레벨 {level}")

print("=== [PART 1] FOR문 영역 종료 ===\n")

# ===========================================================
# [파트 2] while문 중심의 상태 유지 및 입력 제어  
# ===========================================================
print("=== [PART 2] WHILE문 활용 영역 (조건 제어 & 실시간 대기) ===")

# 1. 조건이 만족될 때까지 반복 (몬스터 사냥 시뮬레이션)
monster_hp = 50 
attack_power = 18
hit_count = 0

print(f"체력 50인 야생 외계 생명체 조우! (현재 공격력: {attack_power})")

# 몬스터의 HP가 0보다 큰 동안 계속 공격 (몇 번 안에 죽을지 미리 알 수 없음) 
while monster_hp > 0:
    hit_count += 1
    monster_hp -= attack_power
    if monster_hp < 0:
        monster_hp = 0 #HP가 음수가 되는 것 방지 
    print(
        f"   [턴 {hit_count}] 공격 명중! 몬스터 남은 체력: {monster_hp}/50"
    )
print(f">> 몬스터 처치 완료! (총 {hit_count}번 공격 소요)\n")

# 2. 사용자 입력 검증 및 무한 루프 탈출 (while True + break) 
print("보급품 상자 비밀번호 해킹 시뮬레이션 (정답: 77)")
secret_code = 77
try_count = 0 

# 정답을 맞출 때까지 영원히 반복하는 무한 루프 
while True:
    try_count += 1
    # 시뮬레이션을 위해 자동으로 입력 값을순서대로 대입한다고 가정(50->80->77)
    if try_count == 1:
        user_input = 50
    elif try_count == 2:
        user_input = 80
    else:
        user_input = 77 # 3번째 시도에 정답 

    print(f"   시도{try_count}회: 입력한 숫자 -> {user_input}")

    if user_input == secret_code:
        print("   [성공] 비밀번호가 일치합니다! 상자 해독 완료.")
        break # 조건이 맞으면 while문을 강제로 빠져나감 
    else:
        print("   [실패] 틀렸습니다. 다시 시도합니다.")

print("-" * 50)

# 3. 카운트다운 타이머 (변수를 직접 감소시키며 조건 검사)
timer = 3
print("우주선 비상 탈출 카운트다운:")
while timer > 0:
    print(f"   ...{timer}")
    timer -= 1 # 이 증감식이 없으면 영원히 끝나지 않는 무한 루프에 빠짐!

print("부스터 점화! 발사 완료!")
print("=== [PART 2] WHILE문 영역 종료 ===")

```
