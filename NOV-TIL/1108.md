### 03 if문을 활용한 특정 문제의 로직짜고 코드쓰는것
- 일단은 제 경험상 힘들었던 이유는, 아마도 제가 if루프가 어떻게 돌아가는지 잘 이해를 못해서 그런것같습니다. 
- 개념 다시 이해하기 
```md
- if문은 주어진 조건이 참인지 거짓인지 판단하여 프로그램의 흐름을 분기하는 조건문이다. 
- 조건 자리에 불리언 값이 오지 않아도 자체적으로 참과 거짓을 판별함.
- 조건문 뒤에는 반드시 콜론(:)을 붙이며 조건이 참일때 실행될 코드는 들여쓰기(스페이스 4칸)을 해야함. 
- elif(else if)는 앞 if조건이 거짓일때 새로운 조건이 참일때 실행한다. (여러개 사용가능). 곧 앞 if조건이 참이면 이 새로운 조건은 실행되지 않는다. 
- else는 앞선 모든 조건이 거짓일때 마지막으로 실행한다. 곧 if가 true면 여기는 오지않고, elif까지만 True면 여기에 오지 않는다. 
```
코드예제1
```sh
temp = 20

if temp >= 28:
    print("에어컨을 켭니다.")
    print("1시간 후에 자동 종료됩니다.")
print("프로그램 종료")
```
출력값: 프로그램 종료

```sh
# ========================================================
# AI 우주 조종사 선발 및 등급 판정 시스템 
# ========================================================

print("=== AI 우주 조종사 선발 시스템 시작 ===")

# 지원자 기본 데이터 설정
age = 27

mental_score = 92
simulation_pass = True
special_skill = "HACKING"

print(
    f"지원자 정보 -> 나이: {age}세, 체력 점수: {physical_score}, 정신력"
    f" 점수: {mental_score}"

# ========================================================
# 1. 비교 연산자와 논리 연산자(and, or) 활용

    print("[1단계 심사 통과] 연령 기준(20~39세)을 충족합니다.")

    print("[1단계 심사 탈락] 연력 기준을 만족하지 않습니다.")

# 2. if 조건 설정 순서의 중요성 (학점/등급 판정)
# ========================================================
# 평균 점수 계산
total_score = (physical_score + mental_score) / 2
print(f"지원자 종합 평가 점수: {total_score}점")

# [주의] 순서가 매우 중요합니다! 높은 점수(엄격한 조건)부터 아래로 내려와야 합니다. 
if total_score >= 95:
    grade = "S급 (특급 우주비행사)"
elif total_score >= 85: # 앞의 조건 (95점 이상)이 거짓이고 85 이상인 경우

elif total_score >= 75: #앞의 조건을(85 이상)이 거짓이고 75 이상인 경우 
    grade = "B급 (일반 파일럿)"
else: #위의 모든 조건이 거짓일때 
    grade = "C급 (재시험 대상)"

print(f"판정된 최종 등급: {grade}")
print("-" * 50)

# ========================================================
# 3. 중첩 if문 (Nested If) 활용 
# ========================================================
# 시뮬레이션 통과 여부에 따라 2차 부서 배치 검사 수행 
if simulation_pass == True:
    print("[2단계 심사] 시뮬레이션 테스트를 통과했습니다.")

    # 중첩된 if문: 특수 기술 보유 여부에 따른 보직 배정 
    if special_skill == "HACKING":
        print("-> 특기 확인: 사이버 보안 및 시스템 해킹 전문 요원으로 임명됩니다.")
    elif special_skill == "PILOT":
        print("-> 특기 확인: 메인 함선 선미 주 조종사로 임명됩니다.")
    else:
        print("-> 특기 확인: 일반 전투 지원 부서로 배치됩니다.")
else:
    print("[2단계 심사 탈락] 시뮬레이션을 통과하지 못해 특수 부서 배치 불가.")

print("-" * 50)

# ========================================================
# 4. 한 줄 표기법 (삼항 연산자) 활용 
# ========================================================
# 종합 점수가 80점 이상이고 시뮬레이션을 통과했다면 "최종 합격", 아니면 "예비 후보" 
final_status = (
    "최종 합격" 
    if (total_score >= 80 and simulation_pass == True)
    else "예비 후보" 
)

print(f">> 최종 결과 발표: {final_status}")
print("=== AI 우주 조종사 선발 시스템 종료 ===")
```

### 04 while문을 활용한 특정 문제의 로직짜고 코드쓰는것
- 일단은 while문을 써야하나? 라는 생각이였습니다. 사실 while문까지 써야할 일머리가 돌아가지 않아서 핑계이기는 하지만 이 역시 while문을 왜 써야하는지 모르기 때문에 다시 개념부터 잡아야겠다고 생각했습니다. 
- 개념 다시 알아보기 
```md
- 특정조건이 참(True)인동안 코드를 계속 반복해서 실행하고 싶을때 사용하는 제어문 
- for 문은 횟수나 범위가 정해져있다면, while문은 조건이 만족될때까지 끝을 알 수 없는 반복을 수행할때 쓴다. 
```
코드예제1
```sh
num = 1

while num < 3:
    print(f"현재 숫자는 {num}")
    num += 1
```
출력: 
```md
현재 숫자는 1
현재 숫자는 2
```
코드예제2
```sh
count = 3

```

코드예제4
```sh
#숫자 맞추기 게임 
import random # 난수 발생을 위한 모듈 임포트 

# 1~100 사이의 난수 발생
number = random.randint(1, 100)
# 테스트 할때는 (1, 5) 정도만 

# 시도 횟수
try_count = 0

print("="*40)
print("컴퓨터가 1부터 100사이의 숫자를 생성했습니다.")
print("="*40)

# 메인 루프 
while True:
    user_input = input("컴퓨터의 숫자를 맞춰보세요(1~100): ")

    if user_input == "q":
        print(f"게임 종료합니다. 정답은 {number}입니다.")
        break

    if not user_input.isdecimal():
        print("숫자만 입력해주세요.")
        continue

    if user_input != 101:
        print("100까지만 입력해주세요.")
        continue

    user_number = int(user_input)
    # 시도 횟수 증가
    try_count += 1 

    # 입력값과 정답을 비교 
    if user_number < number:
        print("Up! 더 큰 수 입니다.")
    elif user_number > number:
        print("Down! 더 작은 수 입니다.")
    else:
        print(f"정답입니다. {try_count}회 만에 성공했습니다.")
        break #정답일 경우 무한 루프 탈출 
```
출력: 
```md
========================================
컴퓨터가 1부터 100사이의 숫자를 생성했습니다.
========================================
100까지만 입력해주세요.
게임 종료합니다. 정답은 37입니다.
```
