## 11월 17일 화요일 

### 01 ERD?
```md
Entity-Relationship Diagram(E-R Model)은    
객체-관계 모델로써, 세상의 사물을 개체와 개체 간의     
관계로 표현하는 데이터 모델링 방식
```

### 02 LIMIT?
```md
02 LIMIT?
쿼리 결과로 반환하는 행(Row)의 개수를 제한하는것    
SELECT * FROM users LIMIT 5;
```

### 03 AS?
```md
Alias(별칭, 임시이름)    
SELECT name AS 이름, age AS 나이    
name은 이름으로, age는 나이로 테이블에 보임 
```

### 04 DISTINCT?
```md
조회 결과에서 중복된 데이터를 제거하고 고유한 값들만    
추출할 때 사용 
SELECT DISTINCT 컬럼명 FROM 테이블명;
```

### 05 IS NULL?
```md
특정 칼럼의 값이 NULL(데이터가 없거나 알 수 없는 상태)  
인지 확인하는 조건 연산자 

값이 NULL인 데이터 찾을때는
SELECT * FROM 테이블명 WHERE 컬럼명 IS NULL; 
값이 NULL이 아닌 데이터 찾을때는
SELECT * FROM 테이블명 WHERE 컬럼명 IS NOT NULL;
```

### 06 COUNT
```md
특정 조건이나 범위에 부합하는 행(Row)의 개수를 구하는 집계 함수
```

### 07 BETWEEN
```md
특정 범위(시작값과 종료값 사이)에 포함되는 데이터를 조회할때 사용하는 조건문 
```

### 08 IN (1, 5, 10)
```md
특정 컬럼의 값이 괄호 안에 나열된 목록(1, 5, 10)중 하나라도 일치하는지 확인하는 조건 연산자
```

### 09 LIKE
```md
WHERE 절에서 특정 문자열 패턴을 검색하고 부분적으로 일치하는 데이터를 찾을 때 사용 
```

## 11월 18일 수요일 
### 01 CASE
```md
쿼리 안에서 IF-THEN-ELSE처럼 조건에 따라 다른 값을 반환하는 조건부 표현식
```

### 02 WHEN
```md
CASH WHEN 구문에서 조건을 지정할때 쓰이며 MyBatis 동적 쿼리의 <when> 태그로도 사용 
```

### 03 THEN
```md
CASE 조건문의 일부로 사용되며 특정 조건이 참일때 어떤 값을 반환할지 지정하는 구문
```

### 04 ELSE
```md
주로 SELECT 절 안의 CASE WHEN과 프로시저, 스크립트의 IF, ELSE 두 방식으로 씀. ELSE는 조건이 맞지 않을때 실행할 기본값이나 대체 구문을 지정. 
```

### 05 END
```md
CASE 표현식 종료 또는 BEGIN 블록 종료에 사용
```

### 06 ORDER BY
```md
SELECT로 조회한 결과를 특정 기준에 따라 오름차순(ASC)또는 내림차순(DESC)으로 정렬할때 사용. 
```

### 07 DESC
```md
쓰이는 위치에 따라 내림차순 정렬 또는 테이블 구조조회를 함 
```

### 08 집계함수 MIN/MAX
```md
min은 최소값, max는 최댓값을 구하며, min(컬럼명)/max(컬럼명)이렇게 씀 
```

### 09 집계함수 SUM
```md
숫자형 컬럼의 합계를 구함(null 제외)
```

### 10 집계함수 AVG
```md
숫자형 컬럼의 평균을 구함(null 제외)
```

### 11 ROUND
```md
지정한 자릿수까지 반올림한다. 자릿수를 생략하거나 0을 넣으면 정수를 반올림함 
```

### 12 HAVING
```md
GROUP BY로 묶인 그룹 결과에 조건을 걸어 필터링할때 사용(그룹 단위 필터링). COUNT, SUM, AVG, MAX, MIN같은 집계 함수 결과로 조건을 지정할때 주로 씀 
```

### 13 UNIOIN
```md
세로 결합. 집합 연산자(행 추가, 비교) 여러 SELECT 쿼리 결과를 위아래로 이어 붙이거나 비교. 열 개수, 순서, 데이터 타입이 맞아야 함 

UNION ALL은 중복을 제거하지 않고 모든 결과를 그대로 합침. 정렬, 중복 제거 비용이 없이 빠름 

그냥 UNION은 결과를 합친 뒤 중복 행을 제거 

INTERSECT/EXCEPT(MINUS)는 두 쿼리 결과의 교집합 또는 차집합을 구함 
```

### 14 JOIN
```md
가로 결합. 열 확장. 공통 컬럼을 기준으로 두 개 이상의 테이블이나 쿼리 결과를 옆으로 붙인다 

INNER JOIN은 양쪽으로 조건이 일치하는 행만 반환 

LEFT JOIN/RIGHT JOIN은 한쪽 테이블의 모든 행을 유지하고 반대쪽에서 일치하는 값만 붙임 

FULL OUTER JOIN은 양쪽 테이블의 모든 행을 포함
```

### 15 서브쿼리
```md
SQL 쿼리 안에 중첩된 또 다른 SELECT 문으로 바깥쪽 쿼리를 메인 쿼리, 안쪽 쿼리를 서브쿼리라고 부릅니다. 복잡한 조건 필터링이나 중간 집계 결과를 만들때 사용 

스칼라 서브쿼리(SELECT절)는 행마다 단일 값(1행 1열)을 반환하며 컬럼처럼 출력할때 씀

인라인 뷰(FROM절)는 결과를 임시 테이블처럼 다루며 보통 별칭(AS)을 지정 

중첩 서브쿼리(WHERE, HAVING 절)은 메인 쿼리의 조건을 걸 때 쓰면 반환 행 수에 따라 연산자를 구분 
```

### 02 NumPy.array(ndarray)
```md
동일한 자료형의 원소를 N차원으로 저장하고 빠르게 수치 연산을 수행하는 객체.
```

### 03 numpy.round
```md

```

### 04 arr.sum/arr.mean/arr.max 
```md
arr.sum은 numpy배열(ndarray)의 요소 합계를 계산. 
arr.sum()은 전체 요소의 합을 반환
arr.sum(axis=0)은 열(세로) 방향으로 합계를 구함
arr.sum(axis=1)은 행(가로) 방향으로 합계를 구함

arr.mean은 배열 요소의 산술 평균을 계산하는 메서드
axis를 지정하지 않으면 전체요소를 하나로 합쳐 평균을 구하고 axis를 지정하면 특정 축을 기준으로 평균을 계산.

arr.max는 최대값을 구할때 씀. 
```
