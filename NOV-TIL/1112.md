## 01 docker를 왜 쓰는가
```md
그동안은 내 컴퓨터(로컬 환경)에서만 파이썬 코드가 잘 돌아가도록 세팅했다면, 이제부터는 "내 컴퓨터에서든, 팀원 컴퓨터에서든 1초 만에 똑같이 실행되는 환경"을 만들 수 있게 된다. 
```
```md
예를 들면, 새로운 백엔드 개발자가 팀에 합류하면, 옛날에는 로컬 pc에 직접 파이썬, postgresql, redis를 각각 설치하고 버전을 맞추는데 반나절 이상을 허비했었다. 그런데 이런것을 순식간에 커버 가능한것이 바로 docker를 쓰는 이유다. 
```
## 02 터미널에서 docker 사용하는법
- docker 버전 확인
```sh
docker --version
```
- 이미지 목록 확인
```sh
docker images # 또는 docker image ls
```
- 이미지 다운로드
```sh
docker pull [이미지명] # docker pull hello-world
```
- 이미지 실행할때(실행된다는건 컨테이너로 돌아간다는것)
```sh
docker run hello-world
# hello-world는 이렇게 실행되고 바로 종료되는 이미지
```
- 불러온 이미지 지우고싶을때 
```sh
docker rmi [이미지명] # docker rmi hello-world
```
- 실행되는 컨테이너가 있는지 보는것
```sh
docker ps 
#그래서 hello-world을 실행한뒤 이걸 쳐도 hello-world는 보이지 않음 
```
- 실행이 종료된 컨테이너도 보는법 
```sh
docker ps -a
```
- 종료된 컨테이너 완전히 삭제하는법
```sh
docker rm hello-world
```
## 03 터미널에서 리눅스 OS 이미지받아 구동시키기
```sh
# (git bash shell)
docker image ls # 있나없나 일단 확인

# 해당 이미지를 컨테이너 생성 및 구동하는 작업
docker run -it --name my-server ubuntu:24.04 bash
# --name은 뒤에 이름을 만들기 위해 쓰는것
# my-server은 내가 임의로 이름을 정함
# ubuntu는 리눅스os중 하나
```
컨테이너가 정상적으로 돌아간다면 아래와 같이 뜸 
```md
$ docker run -it --name my-server ubuntu:24.04 bash
root@29fa3406587b:/# '여기부터' 리눅스 명령어 사용가능
```
## 04 터미널에서 nginx 이미지받아 구동시키기
```sh
# (git bash shell)
docker image ls # 있나없나 일단 확인

# 참고로 이미지마다 컨테이너 생성 및 구동하는 작업이 다를 수 있다. 그래서 이부분은 이미지를 받아올때 그 받아오는곳에서 상세설명이 나와있다.
docker run -d --name my-webserver -p 8080:80 nginx

#위 명령이 성공적으로 되면
#61d468ced05a81f31ee0d1397b2efee09934fc0ec1c210c23f338be015df7927
#이런식으로 긴 문장이 뜨고

# curl localhost:8080이라고 치면, 해당 웹서버에 올라간 내용이 뜨게 된다. 
# 해당 코드는 웹사이트 주소창에 검색을 하면 또 그 사이트가 나온다. 
```
## 05 터미널에서 mysql 이미지받아 구동시키기
```sh
# 컨테이너 생성
docker run -d --name my-sql -e MYSQL_ROOT_PASSWORD=admin1234 -p 3306:3306 mysql:8.4

# 컨테이너 구동
docker exec -it my-sql mysql -u root -p

# 비밀먼호 치기 (안쳐지는게 아니라 안보이는것)
# $ docker exec -it my-sql mysql -u root -p
# Enter password:
```

## 06 터미널에서 postgres 이미지받아 구동시키기
```sh
# 일단 이미지를 받아온다
docker pull postgres:18

# 이런식으로 컨테이너 실행
docker run -d --name my-pg -e POSTGRES_PASSWORD=1234 -p 5432:5432 postgres:18
```
