### 문자열
코드 입력1
```sh
print("선발 출전:%s, %d" % ("손흥민",20)) 
#%s는 string의 약어로 문자열을 넣는 자리, %d는 decimal의 약어로 정수를 넣는 자리, 그 뒤에 오는 %는 왼쪽 형식에 오른쪽 값을 끼워 넣는 연산자. 
print("선발 출전:[%5d]" % (20))
#5d는 정수를 최소 5칸 너비로 출력하라는 의미. 뒤에 20은 두칸을 차지하니 공백은 3칸이 추가됨.
print("소수점 표기 : %.2f" % 3.141592)
#%f는 실수를 넣는 자리. .2는 소수점 아래 2자리까지 표시. 
```
실행1
```md
선발 출전: 손흥민, 20
선발 출전: [   20]
소수점 표기 : 3.14
```
코드 입력2
```sh
name = "Cake"
price = 6500
qty = 1

# format 방식
format_str = "주문내역: {0}{1} -> 총 {2}원".format(name, qty, price)
# {0}{1}{2}는 값을 넣을 자리
# name, qty, price 순서대로 대입
print(format_str)

# f-string 방식
format_str = f"주문내역: {name}{qty} -> 총 {(price * qty):>10,}원"
# f는 중괄호 안에 변수, 계산식을 직접 넣겠다는 의미 
# :(콜론)은 뒤에 쓴 서식대로 쓰겠다고 할때 필수.
# >10은 10칸 너비로 오른쪽 정렬 
# ,(쉼표)는 천 단위 쉼표를 표시
print(format_str)

print(f"금액: {14000:>8,}원")
```
실행
```md
주문내역: Cake 1 -> 총 6500원
주문내역: Cake 1 -> 총      6,500원
금액:   14,000원
```
코드입력 3
```sh
# 가상의 주문 데이터 
orders = [
    ("Latte", 5000, 2),
    ("Americano", 3000, 1),
    ("Cake", 6000, 1)
]

print("="*36)
# =를 36개로 쭉 쓰겠다. 
print(f"{'메뉴명':<10} {'단가':>8} {'금액':>9}")
# :<10 10칸 확보후 왼쪽정렬
# :>8 8칸 확보후 오른쪽정렬 
# :>9 9칸 확보후 오른쪽정렬
print("-"*36)

# 총금액 
total_amount = 0

for menu, price, qty in orders:
    subtotal = price * qty
    total_amount += subtotal
    print(f"{menu:<10} {price:>8} {subtotal:>9,}")
    # 메뉴명을 10칸 왼쪽정렬, 단가를 8칸 오른쪽정렬, 금액을 9칸 오른쪽 정렬하고 천 단위 쉼표 표시 
print("-"*36)
print(f"{'합계금액:':<10} {total_amount:>20,}원")
```
실행
```md
====================================
메뉴명              단가        금액
------------------------------------
Latte          5000    10,000
Americano      3000     3,000
Cake           6000     6,000
------------------------------------
합계금액:                    19,000원
```

### 리스트 메서드 
코드입력 
```sh
# append
fruits = ["apple"]
fruits.append("banana") # 맨 뒤에 추가 
print(fruits)

# insert
fruits.insert(0, "kiwi") # 특정 위치에 추가
print(fruits)

# remove
fruits.remove("apple") #삭제할때 
print(fruits)
```
실행
```md
['apple', 'banana']
['kiwi', 'apple', 'banana']
['kiwi', 'banana']
```
